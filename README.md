# LMS Platform – Frontend Web Application

## Overview
The **LMS (Learning Management System) Platform** is a responsive frontend web application designed to present online courses in a clean, structured, and user-friendly interface.

This project focuses on UI clarity, smooth navigation, and modular page design using modern frontend technologies.

---

## Tech Stack
- HTML5
- Tailwind CSS
- CSS
- JavaScript (basic)
- Git & GitHub

## 📄 Pages Description

### 🏠 Home Page
- Introduction to the LMS platform
- Hero section with call-to-action
- Featured courses preview

### 📚 Courses Page
- Displays available courses
- Course cards with images, price, and enroll button

### ℹ️ About Page
- Overview of the LMS
- Vision and mission of the platform

### 📞 Contact Page
- Contact form for user queries
- Displays email, phone number, and location

### ❓ FAQ Page
- Frequently asked questions
- Collapsible sections for better readability
